# C HTTP Server

A HTTP/1.1 server implemented from scratch in C on Linux.

## Goals

This project is designed to explore systems programming concepts including:

- C programming
- POSIX APIs
- Linux sockets
- TCP/IP networking
- HTTP/1.1
- File descriptors
- Filesystem I/O
- Concurrent network programming
- Event-driven I/O
- Linux `epoll`
- Zero-copy file transfer with `sendfile()`
- Memory management
- Error handling
- Testing and benchmarking
